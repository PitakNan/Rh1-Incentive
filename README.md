# Rh1 Incentive — ระบบแปลงตัวชี้วัดเป็นค่าเงิน (เขตสุขภาพที่ 1)

แปลงผลตัวชี้วัดของหน่วยบริการ 103 แห่ง เป็นวงเงินสนับสนุน **โดยไม่ขอข้อมูลจาก รพ. หรือ สสจ. แม้แต่ไฟล์เดียว**
ทุกตัวเลขดึงจากฐานกลางที่เขตถืออยู่แล้วและเดินอัตโนมัติทุกเดือน

- เว็บ: `docs/index.html` (single-file + PWA)
- ท่อข้อมูล: `pipeline/build_incentive_data.py` → `docs/data/incentive_data.json`

## 1. โครงเงิน

```
วงเงินทั้งหมด (ปรับได้)
├── ส่วนที่ 1 — ช่วยเหลือตามตัวชี้วัด        (ค่าเริ่มต้น 70%)
│   ├── 1.1 บริหารแผน Planfin ผ่าน           น้ำหนัก 25
│   ├── 1.2 เคลมติด C / ค้างแก้ น้อยที่สุด    น้ำหนัก 20
│   ├── 1.3 TPS ระดับ A / B                  น้ำหนัก 20
│   ├── 1.4 รักษา Risk Score ไม่เกิน 5       น้ำหนัก 25
│   └── 1.5 เงินบริหารภาพจังหวัด             น้ำหนัก 10
└── ส่วนที่ 2 — ช่วยหน่วยบริการวิกฤต 6-7      (ค่าเริ่มต้น 30%)
    ที่ผ่าน "ประตู" แล้วถ่วงน้ำหนักด้วยค่า K
```

**สูตรกลางของส่วนที่ 1 — วงปิดต่อข้อ ไม่ถ่วงขนาด รพ.** (เจ้าของงานเคาะ 2026-09-19)

```
วงเงินข้อ i      = วงเงินส่วนที่ 1 × น้ำหนัก i ÷ ผลรวมน้ำหนักข้อที่เปิดใช้
เงินที่ รพ. ได้   = คะแนนของ รพ. ÷ ผลรวมคะแนนทุก รพ. ในข้อนั้น × วงเงินข้อ i
```

ผลที่ตามมาที่ต้องสื่อสารกับหน่วยบริการตั้งแต่ต้นรอบ: **ถ้าปีหน้าทุกแห่งดีขึ้นพร้อมกัน เงินต่อแห่งจะลดลง
แม้ผลงานตัวเองเท่าเดิม** เพราะเป็นวงปิดที่แบ่งกัน ไม่ใช่เรตต่อหน่วย

### เกณฑ์คะแนนรายข้อ (ปรับได้ทุกค่าในหน้าเว็บ)

| ข้อ | คะแนน | หมายเหตุ |
|---|---|---|
| 1.1 Planfin | ผ่านทั้ง 2 ด้าน = 2 · ผ่านด้านเดียว = 1 (ปิดได้) | 2 โหมด: **สมมาตร** ±tol (วัดความแม่นของแผน) / **ทิศทางเดียว** (ทำดีกว่าแผนถือว่าผ่าน) |
| 1.2 เคลม | ท็อป 10% = 3 · ท็อป 25% = 2 · ท็อป 50% = 1 | อันดับรวมจาก "ติด C ต่อ 1,000 ครั้ง" + "% ค้างแก้" ปรับน้ำหนักระหว่าง 2 มิติได้ |
| 1.3 TPS | A = 3 · B = 1 · C/D/F = 0 | ให้เฉพาะผู้ผ่านเกณฑ์ตามที่สั่ง |
| 1.4 Risk | 0 ทุกงวด = 5 · ≤1 = 4 · ≤2 = 3 · ≤3 = 2 · ≤5 = 1 · ≥6 = 0 | วัดจาก **ค่าสูงสุดที่เคยแตะทั้งปีงบ** ไม่ใช่งวดล่าสุด — กันการดีดขึ้นลง |
| 1.5 จังหวัด | แบ่งตามจำนวน รพ. หรือเท่ากันทุกจังหวัด | |

### ส่วนที่ 2 — ประตู แล้วค่อยถ่วงน้ำหนัก

```
① มีสิทธิ์  : Risk งวดล่าสุด ≥ 6            (ปรับเป็น ≥5 หรือ =7 ได้)
② ผ่านประตู : ทำได้จริงอย่างน้อย N ข้อ       (ปรับ 1-3 ข้อ)
③ ค่า K     = Σ ( min(%ที่ดีขึ้น, เพดาน) ÷ เพดาน × น้ำหนักข้อ )
④ เงินที่ได้ = K ของเรา ÷ K รวมทุกแห่งที่ผ่านประตู × วงเงินส่วนที่ 2
```

เกณฑ์ตั้งต้น 3 ข้อ (เพิ่ม/ลด/ปรับน้ำหนักได้):

| เกณฑ์ | ทิศทาง | บัญชี GL ที่ใช้ |
|---|---|---|
| เคลียร์หนี้ค่ารักษาตามจ่าย นอก CUP | ลดลง = ดี | `2101020199.202` |
| หารายได้กองทุนอื่นเพิ่ม (ประกันสังคม/ต่างด้าว/กองทุนเฉพาะ) | โต = ดี | `4301020106.*` |
| เงินสดช่องทางอื่น (ใบรับรองแพทย์ + ตรวจสุขภาพ) | โต = ดี | `4313010199.105`, `4301020101.102`, `4301020102.102`, `4301020102.104` |

เทียบ **งวดเดียวกันปีก่อน** เสมอ (ค่าเริ่มต้น ส.ค.69 เทียบ ส.ค.68) เพราะ `bs` ใน GL เป็นยอดสะสม YTD

## 3. สิ่งที่ตรวจแล้ว (2026-09-21)

- ตัวเลขทั้ง 5 แหล่งถูกสอบย้อนรายแห่ง (รพ.สะเมิง) ตรงต้นทางทุกค่า
- ครบ **103/103 แห่งทุกตัวชี้วัด**
- เงินไม่รั่ว: ส่วนที่ 1 + เงินจังหวัด = วงเงินส่วนที่ 1 เป๊ะ · ส่วนที่ 2 = วงเงินส่วนที่ 2 เป๊ะ
  (ทดสอบที่สัดส่วน 0/30/70/100 · ปิดตัวชี้วัดบางข้อ · ปิดทั้งหมด)
- ตรรกะคะแนน: TPS ให้เฉพาะ A/B และ A>B · Risk max>5 ไม่ได้เงินข้อ 1.4 · เคลมแห่งที่แย่สุดไม่ได้เงิน
  · ผู้ได้เงินส่วนที่ 2 ต้องวิกฤต **และ** ผ่านประตูทุกราย
- ไม่มี JS error · มือถือ/ดาร์กโหมด/PWA/สลับแท็บ/เรียง/กรอง ทำงานครบ

## 4. ข้อจำกัดที่ต้องบอกก่อนเอาไปตัดสินจริง

1. **งวดข้อมูลไม่เท่ากัน** — Risk/GL สด ณ 16 ก.ย.69 แต่ Planfin 8 ก.ค. · เคลม 5 ก.ค. · TPS 14 มิ.ย.
   หน้าเว็บขึ้นแถบเตือนและกำกับวันที่รายแหล่งไว้แล้ว **ก่อนเปิดรอบจริงต้องดึงทุกแหล่งใหม่ให้ใกล้กัน**
2. **ข้อมูลเคลมยังไม่ครบปี** — เป็นยอดสะสมเท่าที่สแครปไว้ เทียบกันได้เฉพาะช่วงเดียวกันของทุกแห่ง
3. **ยังไม่มี Deny เป็นตัวเงิน** — ใช้ "ติด C / ค้างแก้" เป็นตัวแทน ถ้าต้องการยอด Deny จริงเป็นบาท
   ต้องเพิ่มการดึง REP เทียบ STM รายหน่วยจาก statementuc (ฐานเดียวกัน ต่อเพิ่มได้)
4. **18 แห่งไม่มีบัญชีหนี้ตามจ่าย** (ในกลุ่มวิกฤตมี 2 แห่ง: เวียงสา, แม่สะเรียง) → ได้ 0 คะแนนข้อนั้น
   โดยอัตโนมัติทั้งที่ไม่ใช่ความผิด — ถ้าจะแก้ ต้องเปลี่ยนเป็นคิดคะแนนเฉพาะข้อที่มีฐาน
5. **วิกฤต 6-7 ยังรับเงินส่วนที่ 1 ได้ด้วย** (16 จาก 24 แห่งเข้าเกณฑ์) — ถ้าต้องการให้รับทางเดียว
   ต้องเพิ่มสวิตช์กันซ้ำ
6. **โหมดเกณฑ์ Planfin เปลี่ยนผลมาก** — สมมาตร ±10% ผ่าน 29 แห่ง · ทิศทางเดียวผ่าน 90 แห่ง
   ต้องเคาะให้ชัดก่อนประกาศ
